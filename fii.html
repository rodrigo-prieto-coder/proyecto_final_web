¿Qué vemos en esta asignatura?

En FII estamos aprendiendo las bases de cómo funciona la informática desde cero.

Contenidos principales:

  • Historia de la informática y cómo han evolucionado los ordenadores.
  • Uso de Git y GitHub para guardar nuestros proyectos de forma segura.
  • Cómo crear páginas web usando HTML para el contenido y CSS para el diseño.
  • Conceptos de redes y sistemas operativos.
